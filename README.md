# Robotic Arm Kinematics Prediction 

## Project Overview
Using Random Forest Regression to predict the (x, y, z) coordinates of a 6-DOF robotic arm 
based on joint angles (q1-q6).

## Results
- Algorithm: Random Forest Regressor
- Optimization: GridSearchCV (3-fold Cross-Validation)
- Evaluation Metrics: MSE, RMSE, MAE, R²
